# streamstats

Простой и удобный потоковый анализатор лог-файлов для форматов CSV и JSONL. 

Программа читает логи построчно (не загружая весь файл в оперативную память), проверяет обязательные поля, считает общую статистику событий по уровням и источникам, находит топ-5 источников ошибок (ERROR и критических), определяет временные рамки (первую и последнюю метку времени) и сохраняет результаты в итоговый JSON-отчёт.

## Установка

Для установки пакета в режиме разработки перейдите в корень проекта и выполните команду:

pip install -e .

## Использование (CLI)

Основной синтаксис команды выглядит так:

python -m streamstats analyze INPUT [INPUT ...] --format csv|jsonl --output REPORT.json

### Разбор параметров командной строки:
- `INPUT` — путь к одному или нескольким входным файлам с логами. Если передать сразу несколько файлов, их статистика корректно объединится в один общий отчёт.
- `--format` — формат входных файлов. Обязательный параметр, принимает значение либо `csv`, либо `jsonl`.
- `--output` — путь к файлу, в который программа запишет итоговый JSON-отчёт со всей статистикой.
- `--skip-invalid` — необязательный флаг режима обработки ошибок. 
  - Без этого флага (по умолчанию) при обнаружении повреждённой строки или неверного формата программа сразу прекращает работу и завершается с кодом ошибки `2`.
  - С этим флагом битая строка пропускается, в лог записывается предупреждение (`WARNING`), а количество пропущенных строк фиксируется в отчёте.

### Примеры запусков:

1. Базовый анализ JSONL-файла:
python -m streamstats analyze valid_logs.jsonl --format jsonl --output report.json

2. Анализ нескольких CSV-файлов с включенным пропуском битых строк:
python -m streamstats analyze log1.csv log2.csv --format csv --output report.json --skip-invalid
